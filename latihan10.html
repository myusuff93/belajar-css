Inline-Level Element in CSS

Elemen inline, tidak seperti elemen tingkat blok, hanya menempati lebar sesuai kebutuhannya dan tidak dimulai pada baris baru. Elemen-elemen ini mengalir di dalam konten, sehingga teks dan elemen inline lainnya dapat muncul berdampingan dengannya.

Elemen inline secara default menerapkan properti CSS `display: inline;`. Properti ini memastikan bahwa elemen tersebut tetap berada dalam alur konten dan tidak berpindah ke baris baru.

Elemen inline yang umum adalah elemen span, a, dan img.
